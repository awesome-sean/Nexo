# 电脑应用程序发布页

当前版本为 **1.0.1**，适用于 Windows x64。

[下载 EXE 1.0.1](https://github.com/sthess548/Nexo/releases/download/v1.0.1/Nexo-Setup-1.0.1.exe) · [使用说明](../../README.md#使用说明) · [手环快应用发布页](band.md)

## 1.0.1

- 并行任务部分完成时，悬浮窗黄绿灯各显示一秒。待处理任务优先显示红灯。
- 下载和校验完成后直接打开 Windows 安装向导，支持浏览器下载。
- 修复长命令误亮红灯。自动审批保持黄灯，审批方式未知时采用十秒兜底。
- 手环配置向导精简为三步，修复安装结束后仍阻止更新和重复安装的问题。
- 设置按钮与“关于 Nexo”增加更新红点，缩小打赏页面二维码。

已安装此前 1.0.1 的用户，请重新下载本页 EXE 并覆盖安装。手环用户安装后，在“关于 Nexo”升级配套快应用。

[GitHub 发布附件](https://github.com/sthess548/Nexo/releases/tag/v1.0.1)
