# Nexo 1.0.1

修复了一些已知问题。

- 修复长命令运行时误亮红灯。明确提问或人工审核立即亮红灯，自动审批保持黄灯，审批方式未知时采用十秒兜底。
- 手环配置向导精简为三步，安装应用后点击“完成”。
- 修复手环应用安装结束后仍阻止电脑端更新、无法再次安装的问题。
- 设置按钮与“关于 Nexo”增加新版本红点提示。
- 缩小微信与支付宝收款二维码。

电脑端版本为 1.0.1，配套手环快应用为 1.0.0。

从 1.0.0 可在“设置 → 关于 Nexo”检查更新。已安装此前 1.0.1 安装包的用户，请重新下载并覆盖安装。
