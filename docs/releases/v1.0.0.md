# Nexo 1.0.0

Windows 电脑端与手环快应用的首发版本。

- 显示 Codex 5 小时额度、每周额度、重置时间和当天花费估算。
- 红灯等待回应，黄灯正在执行，绿灯最近完成。提问和选项题保持红灯，收到对应回答后恢复执行状态。
- Windows 悬浮窗支持外观、大小、透明度和四向停靠，手环支持表情联动与震动提醒。
- 开机自启动时主窗口隐藏到托盘，悬浮窗按保存的开关显示。
- 支持手环快应用安装、卸载及应用内覆盖升级。

## 安装

运行 `Nexo-Setup-1.0.0.exe`。已有测试版可覆盖安装，保留本机设置。连接手环后安装随附快应用，或手动安装 `Nexo-Band-1.0.0.rpk`。

两端显示版本均为 1.0.0，手环内部构建号为 43，沿用原包名与签名，便于覆盖已有测试版。

小米手环 9 标准版已有用户实机确认，9 NFC、10 / 11 标准版与 NFC 版尚未实机检验。震动时长由设备固件决定。

源码、使用说明与界面预览见 [项目首页](https://github.com/sthess548/Nexo)。下载文件均提供 SHA256 校验。
