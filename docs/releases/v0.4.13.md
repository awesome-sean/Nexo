# Nexo 0.4.13

配套手环快应用 1.2.14，构建版本 42。

## 本次更新

- 首次公开 Windows 电脑端、手环快应用与 Rust 蓝牙服务源码，补充使用和构建说明。
- 在「设置 → 关于 Nexo」加入 GitHub 版本检查、一键下载校验和重启覆盖升级。
- 同页加入手环快应用版本比较与覆盖安装，安装完成后读取设备版本确认。
- 手环等待处理提示六组短震＋长震，共十二下，完成提示四次系统长震。
- 同步保留当前任务灯、表情切换、悬浮窗外观及四向停靠功能。

## 安装与升级

首次安装或从尚未支持应用内升级的旧版升级，下载并运行 Nexo-Setup-0.4.13.exe。已有设置和手环绑定保存在用户数据目录。

安装电脑端后连接手环，在「设置 → 关于 Nexo」点击「升级快应用」，也可手动安装本发布随附的 RPK。桌面安装包与独立 RPK 使用同一份手环构建。

小米手环 9 标准版已有用户实机反馈。手环 9 NFC、10 / 11 标准版与 NFC 版尚未实机检验，震动单次时长由设备固件决定。应用内升级流程经过定向检查，真实覆盖升级仍需安装环境验证。
